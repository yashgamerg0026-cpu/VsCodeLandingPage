# VS Code Landing Page

A simple landing page inspired by the official Visual Studio Code website, built using HTML and CSS.

## 🚀 Overview

This project is a front-end recreation of the Visual Studio Code landing page. It features a dark-themed interface with a navigation bar, hero section, supported programming languages, feature highlights, and footer.

## ✨ Features

- **Navigation Bar:** Includes the VS Code logo, navigation links, search icon, theme icon, and download button.
- **Hero Section:** Displays the main heading "Code Editing. Redefined" with a download button.
- **Programming Languages:** Showcases various supported languages, including JavaScript, TypeScript, Python, Java, C++, HTML, CSS, and more.
- **IntelliSense:** Highlights smart code completion features.
- **Debugging:** Showcases built-in debugging capabilities.
- **Extensions:** Highlights the VS Code extension ecosystem.
- **Footer:** Includes copyright information.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 💻 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/VSCodeLandingPage.git
   ```

2. Navigate to the project directory:

   ```bash
   cd VSCodeLandingPage
   ```

3. Open `index.html` in your browser.
